# Pixel & Pose Photography Studio Website

Pixel & Pose is a responsive photography studio website developed as a collaborative course project for **CSC-100L: Application of Information and Technologies**. 

## Team Members (Section: A-Afternoon)
* **Ayma Harris** (2025-CS-329)
* **Zunaira Javed** (2025-CS-303)
* **Hadia** (2025-CS-305)

## Project Features
The application features a structured multi-page user interface designed to simulate a real-world business website:
* **Home Page:** Introduction to the studio, branding, and core visual identity.
* **About Page:** Overview of the studio's background and team profile.
* **Services Page:** Breakdown of photography packages and client offerings.
* **Contact Page:** A functional interface designed for client inquiries and booking management.

## Tools & Technologies Used
* **Frontend:** HTML5, CSS3
* **Design & Wireframing:** Canva
* **Version Control:** GitHub
* **Data Architecture:** Theoretical SQL & Database structure planning

##  How to View
1. Clone this repository to your computer.
2. Navigate into this project folder.
3. Open `index.html` inside any modern web browser to interact with the interface.
